# マリオ再現

## 作品概要

Siv3DとC++を使用し、2D横スクロールアクションゲームを再現した個人制作作品です。

プレイヤーの移動・ジャンプ・当たり判定・敵やアイテムとの接触・
アニメーション・横スクロールなどのゲームシステムを実装しました。

学習目的で制作した再現作品です。

## 開発環境

- OpenSiv3D：0.6.13
- 使用言語：C++
- Visual Studio 2022
- 開発期間：約4か月
- 開発人数：1人

## 主な実装

### プレイヤー操作

左右移動では加速・減速と最高速度を設定し、
慣性を意識した操作を実装しました。

地面に接触している場合のみジャンプ可能とし、
空中では重力を加算して落下処理を行っています。

### 状態・アイテム管理

プレイヤーを

- 通常
- スーパー
- ファイア

の3状態で管理しています。

アイテム取得やダメージに応じて状態を変更し、
サイズや表示するテクスチャを切り替えています。

### 当たり判定

ブロックの上・下・左右に判定領域を設け、

- 着地
- 壁との衝突
- ブロックを下から叩く処理
- 土管との衝突

などを判定しています。

敵との接触では、
上から踏んだ場合と横から接触した場合で処理を分けています。

### ステージ・スクロール

ステージを数値データとして管理し、
値に応じてブロック・土管・ゴール・敵などを配置しています。

プレイヤーが画面中央付近まで移動すると
カメラを移動させる横スクロール処理も実装しました。

### アニメーション

スプライトシートを分割し、
経過時間から表示するフレームを計算することで、
歩行・ジャンプ・ゴールなどのアニメーションを実装しています。
